i How market reference data is used

Price history uses only the ticker and lookback period. DerivaPro computes period return and realized volatility from daily closing-price returns.

Option type, target strike, and target maturity are used only for listed-option implied-volatility lookup. The provider option chain is read, then the nearest expiration and nearest listed strike are selected.

This is a market-reference snapshot, not a production-calibrated volatility surface.

Provider

Market reference data is fetched on demand from Yahoo Finance through the open-source yfinance package. Values may be delayed, adjusted, incomplete, or unavailable for some symbols.
