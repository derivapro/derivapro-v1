ⓘ How market reference data is used

Price history uses only the ticker and lookback period. DerivaPro computes the period return and realized volatility from daily closing-price returns.

Option type, target strike, and target maturity are used only for the listed-option implied-volatility reference. DerivaPro reads the provider option chain, selects the expiration nearest to the target maturity, then selects the listed strike nearest to the target strike.

This is a point implied-volatility lookup from listed option data, not a fitted volatility surface. The nearby-strike IV table gives a small smile/skew context around the selected strike.

Provider

Market reference data is fetched on demand from Yahoo Finance via the open-source yfinance package. Values may be delayed, adjusted, incomplete, or unavailable for some symbols and should be independently validated before production or commercial use.
