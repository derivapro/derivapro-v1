ⓘ How market reference data is used

Price history uses only the ticker and lookback period. DerivaPro computes period return and realized volatility from daily closing-price returns.

Option type, target strike, and target maturity are used only for listed-option implied-volatility reference data. The provider expiration and strike nearest to the targets are selected.

The IV visuals are provider option-chain snapshots, not calibrated production volatility surfaces.

Provider

Market reference data is fetched on demand from Yahoo Finance via the open-source yfinance package. Values may be delayed, adjusted, incomplete, or unavailable for some symbols and should be independently validated before production or commercial use.
